### **📱 Fonctionnalités principales**

#### **1. 🍽️ Menu Digital Interactif**
- Créez votre menu en quelques clics
- Photos, descriptions, prix en FCFA
- Catégories personnalisables
- Disponibilité en temps réel
- Jusqu'à 30 plats (Standard) ou illimité (Premium)

#### **2. 📲 Commandes WhatsApp Automatiques**
- Vos clients commandent directement depuis votre site
- Message pré-rempli envoyé sur WhatsApp
- Zéro commission sur chaque commande
- Notification instantanée en cuisine

#### **3. 📅 Réservations en Ligne**
- Formulaire de réservation intégré
- Confirmation automatique par WhatsApp
- Rappels automatiques
- Gestion des tables par zone (Salle, Terrasse, VIP)

#### **4. 👨‍🍳 Espace Cuisine Temps Réel**
- Commandes en direct avec timer
- Alertes visuelles et sonores
- Gestion des statuts : En attente → En cours → Prêt → Servi
- Interface optimisée pour tablettes

#### **5. 📊 Statistiques Avancées (Premium)**
- Graphiques de revenus (7j, 30j, année)
- Top 5 des plats les plus vendus
- Heures de pointe
- Ticket moyen
- Comparaisons semaine par semaine
- Conseils d'optimisation personnalisés

#### **6. 📄 Facturation PDF (Premium)**
- Factures numérotées automatiquement
- Personnalisation des couleurs
- TVA configurable
- Téléchargement PDF et Reçu
- Pied de page personnalisable

#### **7. 🖼️ Galerie Photos**
- Mettez en valeur vos plats et votre ambiance
- Upload multiple
- Grille responsive
- Visibles sur votre site public

#### **8. ⭐ Avis Clients**
- Collectez les avis de vos clients
- Modération avant publication
- Note moyenne affichée
- Système d'étoiles

#### **9. 💬 Chat Interne**
- Communication temps réel entre staff
- Messages par rôle (cuisinier, serveur, manager)
- Historique des conversations
- Idéal pour la coordination

#### **10. 📦 Gestion des Stocks**
- Suivi des ingrédients et produits
- Alertes automatiques (stock bas/critique)
- Catégories : Viandes, Légumes, Boissons, etc.
- Unités : kg, L, pièce, boîte
- Historique des réapprovisionnements

#### **11. 👥 Gestion du Personnel**
- Rôles : Admin, Manager, Cuisinier, Serveur
- PIN 4 chiffres pour connexion staff
- Permissions par rôle
- Activation/désactivation des comptes

#### **12. 📱 QR Code Restaurant**
- Générez votre QR code personnalisé
- Personnalisation : taille, couleur, fond
- Numéro de table intégré
- Téléchargement PNG/SVG
- Impression des cartes de table

#### **13. 💰 Paiements Multiples**
- Orange Money
- Moov Money
- Wave
- Espèces
- Génération de codes de paiement
- Historique complet

#### **14. 🎨 9 Templates Personnalisables**
- **Basique** : Classique (noir/blanc)
- **Standard** : Soleil, Savane, Marché, Moderne
- **Premium** : Palais Royal, Aurum Nuit, Ignis Feu, Luxe Grill
- Personnalisation : couleurs, polices, logo
- Responsive mobile/tablette/desktop

## 💻 Stack Technique

### Technologies utilisées

**Frontend**
- ⚛️ **React 19.2** - Framework UI moderne
- 📘 **TypeScript 5.8** - Typage statique
- ⚡ **Vite 8.0** - Build tool ultra-rapide
- 🎨 **Tailwind CSS 4.2** - Styling utility-first
- 🧩 **ShadCN/ui** - Composants UI accessibles
- 🎯 **TanStack Router** - Routage file-based
- 🔄 **TanStack Query** - Cache et état serveur
- 📊 **Recharts** - Graphiques interactifs
- 📱 **Lucide React** - Icônes modernes
- 🎭 **Radix UI** - Primitives accessibles
- 📄 **jsPDF** - Génération de factures PDF
- 📱 **QRCode** - Génération de QR codes
- 🔔 **Sonner** - Notifications toast
- 📝 **React Hook Form + Zod** - Formulaires et validation
- 🎠 **Embla Carousel** - Carousels
- 🎬 **Vaul** - Drawers animés
- ⌨️ **CMDK** - Command palette
- 🔢 **Input OTP** - Codes PIN

**Backend**
- 🗄️ **Supabase** - Backend as a Service
- 🐘 **PostgreSQL** - Base de données relationnelle
- 🔐 **Supabase Auth** - Authentification (email, Google OAuth)
- 📁 **Supabase Storage** - Stockage de fichiers
- ⚡ **Supabase Realtime** - WebSockets pour temps réel
- ⚡ **Supabase Edge Functions** - Serverless (2FA email)

**Outils & Infrastructure**
- 🚀 **Nitro** - Server runtime
- 📦 **Workbox** - Service Worker pour PWA
- 🔍 **ESLint** - Linting
- 💅 **Prettier** - Formatage de code
- 🔄 **TanStack Start** - SSR/SSG (désactivé pour simplifier)
